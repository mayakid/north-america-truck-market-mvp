TITLE: BTS TransBorder current-format table structure
SOURCE_URL: https://rosap.ntl.bts.gov/view/dot/38978/dot_38978_DS1.pdf
SOURCE_TYPE: BTS
CONTENT:
Since January 2007, BTS publishes three complementary TransBorder raw tables. Table 1 combines U.S. state, Canadian province and U.S. customs port, but not commodity. Table 2 combines U.S. state, two-digit commodity and Canadian province, and is the training source for province ranking. Table 3 combines port and commodity but not U.S. state or Canadian province. These tables must not be joined as if they represented one shipment-level state + commodity + province + port observation.
